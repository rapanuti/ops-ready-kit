# Code of Conduct

We want this project to be practical, respectful, and welcoming.

## Expected Behavior

- Be kind and direct.
- Assume good intent while still naming concrete problems.
- Prefer actionable technical feedback.
- Respect boundaries, privacy, and maintainers' time.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private information.
- Spam or artificial engagement.
- Repeated low-effort demands without collaboration.

Reports can be sent through the repository security or issue channels when appropriate.
