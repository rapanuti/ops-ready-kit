# LinkedIn Draft

I am building `ops-ready-kit`, an open source CLI for generating operational documentation and deployment readiness artifacts from software repositories.

The project creates a starting point for:

- runbooks
- N1/N2 operations guides
- deployment notes
- architecture summaries
- security checklists
- health check guidance
- Docker, Kubernetes, and CI templates

The focus is practical DevOps/SRE handoff material that can be reviewed, improved, and committed alongside code.

Project: https://github.com/rapanuti/ops-ready-kit
