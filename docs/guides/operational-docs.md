# Operational Documentation Guide

Generated files are starting points:

- `RUNBOOK.md` supports incident response and routine operations.
- `OPERATIONS-N1.md` is for first-line responders.
- `OPERATIONS-N2.md` is for deeper debugging and remediation.
- `ARCHITECTURE.md` summarizes repository signals and expected topology gaps.
- `DEPLOYMENT.md` gives a reviewable deployment baseline.
- `SECURITY.md` lists detected security signals and recommended controls.

Review generated output before committing it to production repositories.
