# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-29

### Added
- Initial CLI for repository analysis.
- Repository scanner for common language, framework, Docker, Kubernetes, CI, and security signals.
- Markdown and HTML operational reports.
- Optional Dockerfile, Compose, Kubernetes, GitHub Actions, and health check artifact generation.
- Initial tests, CI workflow, roadmap, and contribution docs.
