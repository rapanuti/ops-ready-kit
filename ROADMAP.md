# Roadmap

ops-ready-kit grows through small, useful features. Every issue should produce a real improvement that can be tested and documented.

## v0.1.0 - Operational MVP

- Initial CLI.
- Repository scanner.
- Docker, Docker Compose, Kubernetes, CI, and health check detectors.
- Runbook, deployment, architecture, security, and operations documentation generators.
- Markdown and HTML reports.
- Baseline test, lint, type-check, and CI setup.

## v0.2.0 - Better Detection

- Python, Node, Django, FastAPI, Flask, Next.js, and Go heuristics.
- Environment variable inventory.
- Database, cache, queue, and storage detector.
- GitHub Actions detector with workflow summary.
- Risk scoring with actionable remediation.

## v0.3.0 - Deployment Templates

- Safer Dockerfile generation per stack.
- Docker Compose generation with service profiles.
- Kubernetes Deployment, Service, ConfigMap, Secret template, and probes.
- Production checklist mapped to detected components.

## v0.4.0 - Examples and Integrations

- Example Django project.
- Example Node project.
- Example Kubernetes project.
- Integration tests against examples.
- Documentation site.

## v1.0.0 - Stable Operations Kit

- Stable CLI contracts.
- Versioned report schema.
- Release notes and migration guide.
- Broad documentation coverage and real-world examples.
